Bienvenido a mi portafolio final desarrollado para la asignatura de programación.

- **Sitio publicado:** https://github.com/mqfiii
- **Repositorio:** https://github.com/mqfiii/Portafolio-final

## 🚀 Funcionalidades agregadas con JavaScript
- **Saludo dinámico según la hora:** Cambia el mensaje de bienvenida dependiendo del horario local.
- **Alternador de Tema (Modo claro/oscuro):** Permite cambiar la paleta entre un tema rosa pastel y un tema oscuro elegante.
- **Botón Ver más / Ver menos:** Oculta y despliega información adicional en la sección "Sobre mí".
- **Botón Volver arriba (Extra):** Desplazamiento suave de retorno al inicio de la página.
